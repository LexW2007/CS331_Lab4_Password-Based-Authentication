# Lab 4 Question 1

What design principles are applied in this security requirement?

For the authentication failures and user lock functions, the principle is Economy of Mechanism.
This is because the security methods are easy to understand, and they don't inhibit a user's ability to access what they need. Principle of open design is also applied here, because there is no secret on how the passwords are hashed, salted, and stored, but they still work as security mechanisms.
